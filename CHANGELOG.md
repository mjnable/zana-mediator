# Changelog

All Zana packages share one version number and are released together. A release that did
not change this package is not listed.

## 2.0.0-alpha.3 — 2026-10-24

First release of the 2.0 line. Send commands and queries to their single handler through pipeline behaviours (CQRS). Requires PHP 8.5 or later.

Documentation: [the mediator guide](https://github.com/mjnable/zana-docs/blob/main/guides/mediator.md).
